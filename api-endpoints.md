# API Эндпоинты — Puer Pub

> Исключены: аналитика/статистика, баннеры, SMS-верификация, Telegram-интеграция, платежи Tinkoff.

---

## Аутентификация

| Метод | Путь | Назначение | Авторизация |
|-------|------|------------|-------------|
| POST | `/api/register` | Регистрация нового пользователя (email/phone/password) | Публичный |
| POST | `/api/login` | Вход в аккаунт (Passport.js local strategy) | Публичный |
| POST | `/api/logout` | Выход из аккаунта, завершение сессии | Пользователь |
| GET | `/api/user` | Получить данные текущего пользователя | Пользователь |
| PUT | `/api/user` | Обновить профиль (имя, телефон, email) | Пользователь |
| POST | `/api/auth/reset-password` | Сброс пароля по телефону | Публичный |
| POST | `/api/auth/verify` | Проверить валидность admin-сессии | Админ |
